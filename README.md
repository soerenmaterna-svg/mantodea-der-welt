# Mantodea der Welt

Alle bekannten Arten der Gottesanbeterinnen (Mantodea) weltweit – mit Fotos, Verbreitungskarten, Stammbaum, Literatur und Bestimmungshilfe.

Die Fotos werden live von iNaturalist, Wikimedia Commons, Flickr und GBIF geladen (freie Lizenzen, mit Urheberangabe).
Artenliste: Catalogue of Life (Mantodea Species File), GBIF, Wikidata, iNaturalist.
